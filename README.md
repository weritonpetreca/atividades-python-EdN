# Exercícios - Escola da Nuvem ☁️

Este repositório contém a resolução dos exercícios e atividades práticas propostas durante o curso da **Escola da Nuvem**.

## 📚 Sobre o Repositório

Aqui você encontrará códigos desenvolvidos para fixar os conceitos de programação aprendidos em aula, com foco na linguagem **Python**.

## 🗂️ Estrutura de Pastas

- **Pratica-1**: Exercícios introdutórios envolvendo variáveis e cálculos simples (ex: calculadora de preços).

## 🚀 Como Executar

Para rodar os scripts, certifique-se de ter o Python instalado e execute o comando no terminal:

```bash
python nome_do_arquivo.py
```
