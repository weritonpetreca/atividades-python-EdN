# Exercícios - Escola da Nuvem ☁️

Este repositório contém a resolução dos exercícios e atividades práticas propostas durante o curso da **Escola da Nuvem**.

## 📚 Sobre o Repositório

Aqui você encontrará códigos desenvolvidos para fixar os conceitos de programação aprendidos em aula, com foco na linguagem **Python**.

## 🗂️ Estrutura de Pastas

- **Pratica-1**: Exercícios introdutórios envolvendo variáveis e cálculos simples (ex: calculadora de preços).
- **Pratica-2**: Exercícios sobre estruturas de decisão, repetição e funções (ex: conversor de moedas, cálculo de média e descontos).
- **Pratica-3**: Exercícios focados em condicionais e lógica matemática (ex: cálculo de IMC, conversor de temperatura, ano bissexto).
- **Pratica-4**: Exercícios com laços de repetição (`while`), listas e tratamento de erros (`try/except`) (ex: calculadora completa, registro de notas).
- **Pratica-5**: Exercícios com manipulação de strings e funções (ex: calculadora de gorjeta, verificador de palíndromo).


## 🚀 Como Executar

Para rodar os scripts, certifique-se de ter o Python instalado e execute o comando no terminal:

```bash
python nome_do_arquivo.py
```
